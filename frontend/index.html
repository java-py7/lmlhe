Cross-Platform Packaging & Launch Scripts
Zero-configuration startup automation in packaging/
Cross-Platform
The engine is engineered to run seamlessly across Windows, Linux, and macOS without machine-specific assumptions or hardcoded dependencies.
1. Windows (packaging/windows.bat)
Validates Python 3.10+, provisions virtual environment (.venv), installs requirements, detects Ollama daemon / llama-server, checks hardware via WMI/powershell, starts backend, and opens web dashboard.
packaging\windows.bat
2. Linux (packaging/linux.sh)
Executable bash installer. Checks python3-venv, detects CUDA/ROCm, sets ulimits, checks Ollama service or systemd daemon, binds port 8000, and launches default browser.

Detects Apple Silicon (M1/M2/M3/M4) unified memory vs Intel Macs, configures Metal GPU acceleration, activates Apple MLX support, provisions venv, and opens the dashboard.
chmod +x packaging/macos.sh && ./packaging/macos.sh
Local-First Architecture vs Cloud Hosting
Why this engine is built for workstation execution
Local-First
Why public cloud deployment is technically inapplicable: When an AI application is deployed to a public web host (e.g. Vercel, Heroku, AWS), the backend executes on the cloud provider's remote server. A web browser has no operating-system permission to inspect the visitor's local RAM, read local disk files, access local PCI buses, or offload neural weights to the user's discrete GPU.
Local Daemon + Browser UI Pattern: This engine follows the industry-standard architecture used by Ollama, llama.cpp, Stable Diffusion WebUI, and Docker Desktop:
  • The Python engine runs locally as a native background daemon on 127.0.0.1:8000.
  • The browser connects locally to direct OS hardware detection (via psutil, WMI, sysfs, and sysctl).
  • Model weights remain 100% private on local NVMe/SSD/HDD storage without network egress.
  • Zero token cost, zero bandwidth bottleneck, zero cloud vendor lock-in.
Standalone Executable Compilation (PyInstaller)
Package into a zero-dependency self-contained executable
Standalone Binary
To distribute the engine to users without requiring Python to be installed:
# Install PyInstaller pip install pyinstaller # Build self-contained executable with embedded frontend assets pyinstaller --noconfirm --onedir --name "LM-LH-Engine" \ --add-data "frontend;frontend" \ --add-data "storage;storage" \ --hidden-import "uvicorn" \ --hidden-import "fastapi" \ --hidden-import "psutil" \ main.py
Produces a distributable folder dist/LM-LH-Engine/ containing the compiled binary and all assets.
